Сейчас платформа посвящена трём технологиям. У каждой из них своё назначение и свои возможности.

Node.js

Node.js позволяет запускать JavaScript вне браузера. С его помощью можно создавать серверные приложения, инструменты командной строки и многое другое.

Перейти к документации Node.js

Svelte

Svelte — инструмент для создания пользовательских интерфейсов. Он помогает разрабатывать компоненты и приложения с помощью JavaScript, HTML и CSS.

Перейти к документации Svelte

Astro

Astro — веб-фреймворк для создания быстрых сайтов. Он подходит для документации, блогов, страниц проектов и других контентных веб-сайтов.

Перейти к документации Astro
